App: React Native Expo Quran listening app. Main files: app/index.tsx, components/SettingsPanel.tsx, lib/useSettings.ts. Design everything to feel native iOS — clean, minimal, professional.
1. Background Dim Toggle
The background images currently have a dark overlay/gradient applied for text visibility. Add a toggle in settings that lets the user disable this dimming and see the background in its true brightness. When dimming is off, the overlay/gradient should be removed or minimised. Default: dimming on. Add the setting to useSettings.ts with backwards-compatible AsyncStorage migration. Reflect the change instantly when the user toggles it.
2. Arabic Text Rendering Bug
Some Arabic characters or diacritics (tashkeel/harakat) are rendering incorrectly — appearing as a white dot inside a dotted circle. This is a font fallback indicator meaning the character is not found in the loaded font. Investigate thoroughly: check which font is loaded (UthmanicHafs), verify it covers the full Unicode range needed for Quranic Arabic including all diacritics, and check whether the font is fully loaded before text renders. Fix the root cause — do not mask it. If the font does not cover certain characters, find and bundle a replacement that does. Ensure expo-font has fully loaded the font before any Arabic text is rendered.
3. Rapid Skip Button Breaking Playback
When the next/previous verse buttons are pressed rapidly, the UI breaks — the play/pause button stops working and audio stops playing entirely. This is a race condition. Multiple setIndex calls fire before the previous player has finished seeking or the new listener has attached. Fix this by: debouncing or throttling the skip buttons so rapid taps are ignored until the current transition is complete, ensuring seekTo(0) and play() are never called on a stale or already-removed player, and making sure the isPlaying state and player state are always in sync after rapid skips. Do not break normal single-tap skip behaviour.
General: Do not break any existing features. Match existing design system exactly. Keep TypeScript valid throughout.
